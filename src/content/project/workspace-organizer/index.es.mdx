## Organizar contextos a nivel de ventana

Workspace Organizer es una aplicación nativa para macOS que agrupa ventanas individuales de las aplicaciones en espacios enfocados dentro de espacios de trabajo con nombre. Un espacio de trabajo puede representar lo personal, el trabajo o un proyecto específico, mientras que espacios como Navegador, Código e IA mantienen juntas las ventanas correspondientes.

La distinción a nivel de ventana es la idea central. Una ventana de Safari para navegar por asuntos personales no debería tener que moverse junto con otra dedicada al trabajo de un cliente solo porque ambas pertenecen a la misma aplicación.

### Objetivos

</ProjectSectionHeading>

<ProjectIntentBrief labelledBy="goals">

<li>

**Organizar ventanas individuales** sin depender de las API privadas de Spaces en macOS.

</li>

<li>

**Restaurar la disposición, no solo la lista de aplicaciones**, con posiciones y tamaños que tengan en cuenta las pantallas.

</li>

<li>

**Agilizar el cambio de contexto** desde la aplicación, la barra de menús, el teclado, el trackpad, Atajos, las URL o una CLI.

</li>

<li>

**Mantener local el contexto sensible**, evitando títulos de ventanas y URL en los diagnósticos y la sincronización.

</li>

</ProjectIntentBrief>

### Resultados

</ProjectSectionHeading>

- **Una alternativa a nivel de ventana** al cambio de tareas a nivel de aplicación.
- **Varias formas de retomar un contexto** sin imponer un único modelo de interacción.
