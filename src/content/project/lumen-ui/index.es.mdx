## Un lenguaje compartido para interfaces web y nativas

Creé Lumen UI para llevar un lenguaje visual consistente a distintos productos, respetando la forma
de construir de cada plataforma. Astro, React y Web Components basados en estándares comparten contratos web;
React Native, SwiftUI y Jetpack Compose extienden esas bases a interfaces nativas.

Los tokens compartidos y los contratos explícitos de componentes conectan el sistema. Los adaptadores de cada framework controlan
su renderizado e interacción: mejora progresiva para Astro, componentes y hooks para React,
elementos personalizados para el navegador y composición nativa para aplicaciones móviles y de escritorio.
Las aplicaciones conservan sus reglas de negocio, datos, enrutamiento y políticas de recuperación.

</ProjectContextLead>

<ProjectCapabilitySpread labelledBy="what-lumen-4-brings-together">

<ProjectCapabilityEntry number={1} title="Controles accesibles y respuestas de estado">

botones, paneles desplegables, diálogos, campos, acciones de portapapeles, progreso y estados de error con contratos explícitos de interacción.

</ProjectCapabilityEntry>

<ProjectCapabilityEntry number={2} title="Interfaces operativas">

tablas de datos, calendarios, composiciones Kanban, navegación y plantillas completas de paneles que las aplicaciones componen alrededor de su propio estado y sus flujos.

</ProjectCapabilityEntry>

<ProjectCapabilityEntry number={3} title="Datos y presentación">

gráficos, `WorldMap`, `DeviceFrame` y comparación de imágenes para historias de producto, analítica y experiencias multimedia legibles.

</ProjectCapabilityEntry>

<ProjectCapabilityEntry number={4} title="Movimiento moderado">

grupos de aparición, números animados y movimiento de composición con contenido estable y opciones de movimiento reducido.

</ProjectCapabilityEntry>

<ProjectCapabilityEntry number={5} title="Bases nativas">

adaptadores de React Native, SwiftUI y Compose, junto con interfaces específicas de WidgetKit y Wear OS que respetan sus plataformas.

</ProjectCapabilityEntry>

<ProjectCapabilityEntry number={6} title="Recursos de diseño e IA">

una biblioteca de Figma, una habilidad portable para agentes, un catálogo MCP, recetas de CLI, `llms.txt` y contratos de componentes y estilos legibles por máquinas.

</ProjectCapabilityEntry>

</ProjectCapabilitySpread>
