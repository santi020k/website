## Scope and versioning

Version 4.1.0 is the editorial refresh of the existing v4 visual identity. The
approved designs extend across Home, About, Work, Projects, case studies, Blog,
articles, series, speaking, the resume, legal and recovery pages, and shared
contact surfaces. They include portrait and cover spreads, folios, ledgers,
margin-based metadata, article illustrations, technology strips, and reading
navigation. Responsive layouts, both themes, keyboard access, enlarged text,
and reduced motion remain part of the release contract.

The release also adds the website history timeline and maintained v1, v2, and v3
archives, a private history-film studio, refreshed project discovery and product
previews, and the Timeline career layout. The History page includes the approved
Chapter spread hero and Split exhibit chapter captures. Reading, search, asset
delivery, metadata, and offline recovery improvements accompany the visual work.
`CHANGELOG.md` contains the generated release notes; older release entries remain
unchanged. This release retains 4.1.0 rather than introducing a new design generation.

`pnpm run version-packages` consumes the pending Changesets and sets the root
website package to 4.1.0. Historical apps keep their original version labels and
remain excluded from release versioning. The existing lockfile and dependency
versions are retained. Both resume PDFs were regenerated because their source
fingerprint includes the root manifest and shared render dependencies. All five
pages match the preserved release PDFs in extracted text and rendered pixels.

The preserved `fix/reveal-threshold-cleanup` checkpoint is intentionally excluded.
Its shared-runtime proposal changed custom reveal timing and was rejected; the
current site retains explicit viewport-entry thresholds and their regressions.
See [Tall reveal groups](../lumen-integration.md#tall-reveal-groups).
